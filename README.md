# Lash Room

Индивидуальный сайт школы-студии наращивания ресниц в Санкт-Петербурге.

## Запуск

Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

Статическая сборка находится в `dist/`. Относительный `base` позволяет разместить сайт в подкаталоге, включая GitHub Pages. Автоматическое публичное развёртывание не настроено.

## Реализовано

React, TypeScript, Vite, Tailwind CSS 4, Motion, Lucide. Адаптивная композиция, мобильное меню, фиксированная мобильная запись, раскрывающиеся вопросы, карта с загрузкой по нажатию, звонок, WhatsApp и существующая запись в DIKIDI. Поддержка reduced motion, клавиатурного фокуса, семантической навигации. Отправки форм и сбора персональных данных нет.

По правилам среды сервер предпросмотра без этого инструмента не запускается. Не считать браузерную приёмку завершённой.
