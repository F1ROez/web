# Эстакада — автомобиль в порядке

Индивидуальный демонстрационный сайт автосервиса: React 19, TypeScript, Vite, Tailwind CSS 4, Motion, Lucide.

## Запуск

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```
