# На Зольной — автомойка самообслуживания

Индивидуальная демонстрационная концепция для автомойки на Зольной улице, 5а, Санкт-Петербург. React + TypeScript + Vite + Tailwind CSS + Motion + Lucide.

## Запуск

```sh
npm ci
npm run dev
```

Продакшен: `npm run build`. Результат в `dist/`; `npm run preview` — локальный просмотр сборки. Относительная база Vite позволяет разместить сборку в подкаталоге, включая GitHub Pages. Публикация и GitHub Pages автоматически не включаются.

## Реализовано

Адаптивный лендинг: hero, подтверждённые возможности, порядок заезда, FAQ-аккордеон, мобильное меню, телефон, WhatsApp, ссылки на маршруты в 2ГИС. Интерактивная OpenStreetMap загружается по нажатию. Схема до загрузки — декоративная, не географическая карта. Анимации учитывают prefers-reduced-motion. Фальшивых форм, онлайн-записи и вымышленных цен нет.

## Фактическая проверка

- `npm install --no-audit --no-fund` — успешно.
- `npm run build` — TypeScript и production-сборка Vite успешно.
- Обе локальные фотографии открыты и осмотрены.
- Проверены соответствие якорей секциям, номера телефона и ссылки WhatsApp исходной карточке, логика меню/FAQ/загрузки карты по исходному коду.
- Дополнительный проход по CSS: мобильные колонки, размеры заголовков, мобильная навигация, фиксированный CTA, focus-visible и reduced motion.
- Браузерная проверка десктопа/телефона не выполнена: в сеансе отсутствует вызываемый инструмент `cua_repl.js`. Поэтому отсутствие переполнений и фактическая загрузка карты во внешнем браузере не подтверждены. Нельзя считать визуальную QA завершённой до такого просмотра.
