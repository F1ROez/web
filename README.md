# Family Club by Ola Dementeva

Индивидуальная демонстрационная концепция сайта салона. React 19, TypeScript, Vite, Tailwind CSS 4, Motion и Lucide. Молочная палитра, бордовый акцент, редакционная типографика и адаптивная композиция.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Продакшен: `npm run build`; просмотр сборки: `npm run preview`.
Vite использует относительные пути: сборку dist можно разместить в подкаталоге.

## Функциональность

- Мобильное меню, якорная навигация, доступные раскрывающиеся услуги.
- Три филиала, переключение карты и ссылки Yclients для каждого адреса.
- Телефонные ссылки, Telegram, email и маршруты.
- Клавиатурное управление вкладками, видимый фокус, reduced motion.
- Никаких имитирующих отправку форм, выдуманных отзывов или цен.

## Проверка

`npm run build` успешно проверяет TypeScript и собирает production-версию. Изображения скачаны локально. Проведена проверка исходных ссылок, логики меню, вкладок, аккордеона и адаптивных CSS-правил. Браузерная визуальная проверка, скриншоты мобильной/десктопной версии и полный сценарий записи не выполнены: в сессии отсутствовал разрешённый браузерный инструмент. Это следует проверить перед публикацией.
